# 拉曼光谱绘图默认提示词

当用户要求“根据数据绘制拉曼图像”“处理 Raman 数据”“绘制拉曼光谱”“批量生成 Raman 图”或类似任务时，自动使用本 skill 和本提示词。

请对用户提供的 Raman 光谱 `.txt` / `.csv` / 两列数据文件进行批量绘图处理。默认每个数据文件为两列：第一列是 Raman shift，第二列是 intensity。除非用户明确要求叠加图，否则每组数据单独生成一张 Raman 图。

绘图要求：

1. 新建一个专门文件夹保存处理后的 Raman 图像，不覆盖原始数据。
2. 横坐标范围按用户最新要求设置；如果用户说“按之前要求”或没有重新指定，默认使用 `0-1600 cm^-1`。
3. 只标注当前横坐标范围内的峰位。
4. 曲线颜色要加深、线条加宽：
   - 300 系列普通样品用深红色 `#D00000`。
   - 400 系列和 si 系列样品用深蓝色 `#0047B3`。
   - origin 或原始对照样品用深紫色 `#8A00CC`。
   - 默认线宽使用 `2.15`。
5. 使用 Times New Roman 风格，坐标轴和文字加粗，黑色坐标轴边框。
6. 横轴标题为 `Raman Shift (cm^-1)`，图中应显示为上标格式；纵轴标题为 `Raman Intensity (offset)`。
7. 隐藏 y 轴数字，仅保留刻度线。
8. 标注主要峰值位置：用黑色竖向虚线和峰位数字标注。
9. 特别标注 C 的峰位置：
   - D 峰标注为 `C-D`，在约 `1280-1450 cm^-1` 范围内寻找。
   - G 峰标注为 `C-G`，在约 `1500-1650 cm^-1` 范围内寻找；如果横坐标最大值为 1600，则只在 `1500-1600 cm^-1` 范围内寻找。
10. 每张图同时保存为 `.png` 和 `.svg`，并生成 `peak_positions.csv` 峰位汇总表。
11. 如果处理多张图，请额外生成 `contact_sheet.png` 方便检查总览。
12. 完成后告诉用户输出文件夹路径，并简要说明生成了哪些文件。

执行时请先检查数据格式和坐标范围，再开始绘图；完成后打开总览图或代表性图像确认效果。
