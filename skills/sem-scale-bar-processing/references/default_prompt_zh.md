# SEM 图像标度尺处理默认提示词

当用户要求“处理 SEM 图片”“修改 SEM 图像”“移动标度尺”“删除底部无效内容”“批量处理 tif/SEM 图片”或类似任务时，自动使用本 skill 和本提示词。

请对用户提供的 SEM 图像文件或文件夹进行批量处理。目标效果是：删除图像底部无效内容/仪器导出信息区，将标度尺重新绘制到 SEM 图像内部，使最终图像只保留有效显微图像区域和清晰标度尺。

默认处理要求：

1. 新建专门文件夹保存处理后的 SEM 图像，不覆盖原图。
2. 支持 `.tif`、`.tiff`、`.png`、`.jpg`、`.jpeg`、`.bmp`。
3. 自动裁掉底部无效内容；如果自动判断不理想，根据用户反馈更新裁剪参数或脚本默认规则。
4. 标度尺绘制到图像内部左下角。
5. 标度尺必须与原图一致：优先检测原图中的标度尺像素长度，并根据原图标签或显微镜元数据推断原始标度文字，例如 `1 µm`、`2 µm`、`5 µm`。不得随意改成默认 `1 µm`，也不得按图像宽度任意缩放标度尺。
6. 如果无法从原图或元数据可靠推断标度尺长度/文字，必须要求用户提供明确的 `--bar-length-px` 和 `--scale-label`，不要静默生成不可信标度尺。
7. 字体使用 Arial。
8. 字体要偏小，并按标度尺长度自动匹配：整段标度文字的宽度应尽量等于水平标度尺长度。
9. 标度尺和文字使用白色；可保留轻微黑色阴影以提高可读性。
10. 只绘制水平白色标度尺，不保留也不重新绘制右侧或左侧白色细竖线。
11. 输出优先使用 `.png`，并保留原始文件名主体。
12. 批量处理时生成 `contact_sheet.png`，用于快速检查所有图的效果。
13. 完成后告诉用户输出文件夹路径和处理数量。

执行时优先使用 `scripts/process_sem_scale_bar.py`。如用户在后续任务中提出稳定的新要求，例如标度尺位置、字号、线宽、裁剪比例、输出格式、文件夹命名规则或标度文字，请把该要求更新到本提示词、`SKILL.md` 或脚本中，让本 skill 持续改进。
